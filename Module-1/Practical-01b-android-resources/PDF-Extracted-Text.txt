2.Android Resources: Colors, Themes, Strings, Drawables, Dimensions, Images
AIM:To study and implement Android Resources such as Color, Theme, String, Drawable,
Dimension, and Image in an Android application.
THEORY:
Android resources are external values used in an app to define UI components without
hardcoding. They help maintain consistency, reduce errors, and support localization.
Types of Android Resources Used in This Practical
    1.  Color Resource (colors.xml)
       Stores all color codes for use across the application.
    2.  String Resource (strings.xml)
       Stores text messages, titles, labels, etc., making localization easier.
    3.  Drawable Resource (drawable/)
       Stores images (PNG, JPG, WebP) and XML shapes (rectangles, circles, gradients).
    4.  Dimension Resource (dimens.xml)
      Used to store sizes such as padding, margin, text size.
    5.  Theme/Style Resource (styles.xml)
       Defines consistent UI styles.
    6. Image Resource
      Images stored under drawable folders.
1. colors.xml
File: res/values/colors.xml
<resources>
  <color name="appPrimary">#6200EE</color>
  <color name="appSecondary">#03DAC5</color>
  <color name="white">#FFFFFF</color>
  <color name="black">#000000</color>
</resources>
2. strings.xml
File: res/values/strings.xml
<resources>
  <string name="app_name">Resource Demo App</string>
  <string name="hello_text">Hello World using Android Resources!</string>
</resources>
3. dimens.xml
File: res/values/dimens.xml
<resources>
  <dimen name="text_large">24sp</dimen>
  <dimen name="padding_normal">20dp</dimen>
  <dimen name="image_size">150dp</dimen>
</resources>
