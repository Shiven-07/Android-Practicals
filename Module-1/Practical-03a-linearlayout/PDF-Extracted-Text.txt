Basic Layout Management
  1. Develop an Android application using LinearLayout (Horizontal and Vertical) to design
     structured UI.
  2. Develop an Android application using RelativeLayout to align UI components
     dynamically.
  3. Develop an Android application using TableLayout to design a structured
     Login/Registration Form.


  AIM:To Study LinearLayout, RelativeLayout, TableLayout

 THEORY

  Android Layouts define the structure of UI elements on the screen. Each layout arranges
  elements differently.

   1. Linear Layout

  Arranges elements vertically or horizontally.

   2. Relative Layout

   Positions views in relation to parent or other views.

   3. Table Layout
  Arranges elements in rows and columns similar to tables
