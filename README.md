## 🛠️ How to use

1. Open the practical folder.
2. Read `README.md` and `Original-Pages.pdf`.
3. View `.java` and `.xml` excerpts where available.
4. Build the Android Studio project and configure dependencies/resources as needed.

> **Note:** This repository is a study reference extracted from a PDF, not a set of verified executable Android Studio projects. Some index entries have no separate implementation and share the same pages. Never assume a source excerpt is complete or runs unchanged.
